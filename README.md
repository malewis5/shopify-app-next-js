# shopify-app-nextjs

[![npm version](https://img.shields.io/npm/v/shopify-app-nextjs)](https://www.npmjs.com/package/shopify-app-nextjs)
[![npm downloads](https://img.shields.io/npm/dm/shopify-app-nextjs?label=downloads)](https://www.npmjs.com/package/shopify-app-nextjs)

A TypeScript package for building embedded Shopify apps with the Next.js App Router.

## Getting Started

This project is under active development and is not ready for production use. The Shopify integration APIs are still being designed and built.

## Installation

```bash
npm install shopify-app-nextjs
# or
yarn add shopify-app-nextjs
# or
pnpm add shopify-app-nextjs
# or
bun add shopify-app-nextjs
```
